# Growth360
Digital Growth Intelligence platform.

This repository uses a compact source archive with a root Dockerfile for Render deployment.
The runtime source files are stored in source.tar.gz and unpacked during the Docker build.

## Deployment
Render Blueprint: render.yaml
Health endpoint: /api/health

## Environment variables
- ENVIRONMENT=production
- GROWTH360_ADMIN_TOKEN (generated by Render)
- GROWTH360_DB=/var/data/growth360.db
- PAGESPEED_API_KEY (optional)
- DATAFORSEO_LOGIN / DATAFORSEO_PASSWORD (optional market data integration)

Market intelligence data must be labelled as estimated where applicable. First-party analytics require client authorization.
